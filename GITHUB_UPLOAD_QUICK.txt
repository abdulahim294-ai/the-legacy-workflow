## 🆘 Need Help?

### Common Issues

**Q: "fatal: remote origin already exists"**
A: Run `git remote remove origin` first

**Q: "Authentication failed"**
A: Check your token is correct and not expired

**Q: "Large files warning"**
A: Use Git LFS for files > 50MB

**Q: Files not showing**
A: Check .gitignore isn't blocking them
